# Snyk (SCA)

## Description

Snyk merupakan Software Composition Analysis (SCA) tool yang digunakan untuk mendeteksi library atau dependency yang memiliki vulnerability.

## Purpose

- Detect vulnerable dependency
- Check CVE
- Dependency recommendation

## Target

OWASP WebGoat Dependency

## Scan Command

```bash
snyk test
```

## Expected Output

- Vulnerable Package
- Severity
- CVE
- Upgrade Recommendation
